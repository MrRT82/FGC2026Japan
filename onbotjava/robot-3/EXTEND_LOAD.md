# 展開負荷の比較計測（load_v3）

対象は `MainClass_Blue_Timing` のみ。識別子は `20260923_162905_robot3_blue_timing_load_v3`。
通常Blue/Redと関連22Javaは9157b47と一致。計測版もPIDゲイン・重力/摩擦補償・詰まり判定・目標指令の計算は変更していない。新しい負荷補正やボール数の自動推定はまだ行わない。

## 操作

1. Blue計測版を選びINIT。gamepad2の十字キー右/左を押すたびに試験開始時の実際のボール数を増減する。初期値-1は未設定、0は空。画面で確認する。この入力はINIT中だけ有効で、運転中の操作割当ては変えない。
2. START後、従来どおり前後スティックで本動作とCSV記録を開始する。計測版も通常の走行・機構操作を行うため、スティック入力で車体が動き得る。
3. 空・既知の少量・満載などで、同じ操作、同じ角度区間の上昇/下降/保持をそれぞれ複数回記録する。個数条件ごとにOpModeを終了して新しいログを作る。通常STOPで保存する。
4. 試験中に吸入/発射して個数が変わった部分は比較に使わない。ラベルは「開始時の個数」で、自動追跡しない。同じ個数でもボール配置によるばらつきを調べる。電池電圧や他機構の動作条件も揃える。
5. `/sdcard/FIRST/logs/robot_blue_timing_日時.csv` を取り出す。生ログはGitHubに入れない。

## 取得方法と追加列

CSVは従来どおり50ms以上間隔。展開電流はCSV生成時に100ms以上間隔で1回取得する。巡回電流取得の展開スロットとINIT時の展開電流取得を外し、二重読取りを避けた。`currentLimit=0`でも負荷計測は有効。他の電流・電圧取得の巡回順は維持する。

電流取得直前に、直近の展開制御状態をコピーする。ポテンショ・速度の追加取得はしない。厳密な同時測定ではなく、センサー内部のサンプリング時刻も保証しない。連続したCSV行に同じサンプルを載せる場合、`load_seq`と状態値をまとめて保持する。

| 列 | 意味 |
|---|---|
| load_seq / load_t_ms | 取得試行の連番 / 最初の負荷取得からの単調時計経過ms。同じ連番は解析で1回だけ数える |
| load_initial_balls | INIT中に入力した開始時の個数。-1は未設定 |
| load_current_A / load_current_ok | モーター電流 / 有効値なら1。例外はNaNと0になり、無負荷と誤認させない |
| load_read_ms | 状態コピーと電流API呼出しの経過時間。API単独はtm_diag_extendに集計 |
| load_angle_deg / load_velocity_dps | 直近の制御用角度 / フィルタ済み角速度。正負は角度の増減であり、物理的な上下との対応は実機で確認 |
| load_angle_age_ms | 角度API完了から電流取得直前までの経過ms。未取得は-1 |
| load_target_deg / load_goal_deg | 直近の通常PID計算に使った目標角度 / 現在の最終目標。入力による目標変更は次の制御周期に反映される場合がある |
| load_requested_out / load_sent_out | 制御器の最終出力 / CachedPowerが最後に送信した指令。後者も実測トルク・端子電圧ではない |
| load_ff / load_pid / load_i | 重力+摩擦FF / PID合計 / ki×積分状態。保護・逆転時は通常PIDの内訳として解釈しない |
| load_control_dt_ms / load_raw_dt_ms | 制御計算で使った制限済みdt / 制限前の実測dt |
| load_stuck / reverse / stall / pote_fault / yield | 詰まり・逆転・停止保護・ポテンショ異常・電力譲渡の各フラグ（全てload_接頭辞） |
| load_voltage_V / load_voltage_age_ms | 既存のHub電圧キャッシュ / 取得終了からの経過ms。電流とは非同時、複数Hub時は最小電圧 |
| load_period_ms | 該当ループ先頭間の周期。今回の電流取得の負荷は次の周期に現れる |

既存ext_cur_Aも最新の専用サンプル値になる。角度等との対応にはload_列を使う。追加取得時間は既存タイミング列で確認できる。電流の取得頻度を増やした分、計測版の周期に影響する可能性がある。通常版には影響しない。

## 解析

```text
python -B tools/analyze_extend_load.py empty.csv three_balls.csv full.csv
python -B tools/analyze_extend_load.py trial.csv --from-ms 2000 --to-ms 8000 --max-accel 50
```

時間範囲はload_t_ms基準。出力は実行ログ別・開始個数別・角度10度帯・正負方向別・速さ5度/秒帯の電流平均/標準偏差/範囲、電圧、位置誤差、出力、出力飽和割合、周期、取得時間。絶対速度2度/秒以内は保持として分離する。

重複連番、非有限値、取得失敗、保護/逆転、角度の古さ100ms超、取得50ms超、制限前dtが2～100ms外、無効電圧/電圧の古さ500ms超を除外する。連続する異なるサンプルのフィルタ済み速度差から加速度を計算し、初回、0.5秒超の間隔、既定で絶対加速度50度/秒²超も除外する。閾値は探索用であり、計測遅延・ノイズ・機構に合わせて調整する。標準偏差はサンプルの散らばりで、独立試行の信頼区間ではない。

同じ帯でも細かい角度・速度差、電圧、摩擦、球配置が違う場合がある。生データも確認し、反復試験の分布が重なるかを見る。個数別に分かれれば個数推定を検討し、軽重だけ分かれるなら負荷別補償を検討する。差が出なければこの計測条件では推定困難。負荷だけから正確な個数が決まると仮定しない。
